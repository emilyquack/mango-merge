# Mango Merge

A cute pastel fruit merge web game with Mango and Kiwi the Cat.

## Controls

- Arrow keys or WASD
- On-screen buttons
- Swipe on the board

## Publish with GitHub Pages

Create a new GitHub repository, then from this folder:

```bash
git init
git add .
git commit -m "Create Mango Merge website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/mango-merge.git
git push -u origin main
```

Then in GitHub: Settings → Pages → Deploy from branch → main → /root.
